# Weather Forecasting Web Application

A simple and user-friendly Weather Forecasting Web Application that provides real-time weather information for any city using the **OpenWeatherMap API**.

# Features

- Search weather information by city name.
- Display current temperature in Celsius.
- Show weather conditions and descriptions.
- Display feels-like temperature.
- Show humidity levels.
- Display wind speed.
- Dynamic weather icons based on current conditions.
- Error handling for unsuccessful API requests.

# Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling and responsive layout.
- **JavaScript** – Application logic and API integration.
- **OpenWeatherMap API** – Fetching real-time weather data.
